# Overview

A Flutter/Dart App that records a Travel Journal with picture and text.

The application has a home page that shows a text input field and two buttons to create a journal entry,

add the picture using the device camera access permissions and saves the Journal entry

A journal list page displays all the Journal entries in list form with options to delete or view and edit each entry.

This app is a simple demostration of a mobile application written in Dart and Flutter UI

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

The stack is vscode, dart and flutter and runs on multi platform with single codebase

The main program logic is wriiten in dart and flutter. The essential UI was built on the Flutter sample app namer_app.
